DEMO-MODUS

Dies ist eine Demonstration.

In der Produktion würden Sie jetzt zur echten Zahlungsseite von PayPal oder Stripe weitergeleitet.

Für diese Demo wird die Bestellung in 3 Sekunden automatisch bestätigt.

So funktioniert die Integration:

  • PayPal: Kunde wird zu PayPal weitergeleitet → Zahlung autorisieren → Zurück zur Website → Bestellung bestätigt
  • Stripe: Kunde wird zu Stripe Checkout weitergeleitet → Karte eingeben → Zurück zur Website → Bestellung bestätigt
  • Backend erforderlich: API-Keys sicher auf dem Server speichern

Wichtig für Produktivbetrieb:

1. Aktivieren Sie die Zahlungsmethode in payment-config.js
2. Fügen Sie Ihre API-Keys hinzu (PayPal Client ID oder Stripe Publishable Key)
3. Erstellen Sie Backend-Endpunkte für sichere Zahlungsverarbeitung
4. Siehe Kommentare in payment-config.js für Beispiel-Code
