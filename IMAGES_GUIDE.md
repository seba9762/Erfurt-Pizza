## 📥 How to Download and Add Images

### Step 1: Download Images

1. **Go to Unsplash** (example):
   ```
   https://unsplash.com/s/photos/margherita-pizza
   ```

2. **Find a photo you like**

3. **Click "Download free"**
   - Choose "Medium" or "Large" size
   - No signup required!

4. **Save to your computer**
   - Name it properly: `pizza-margherita.jpg`

### Step 2: Optimize Images

Before adding to your website, **compress them**:

1. **Go to TinyPNG**:
   ```
   https://tinypng.com/
   ```

2. **Drag your image**
   - It reduces file size by 50-70%
   - Keeps quality!

3. **Download optimized image**

### Step 3: Add to Your Website

1. **Place image in folder**:
   ```
   Put the file in: assets/menu/
   ```

2. **Name it correctly**:
   ```
   pizza-margherita.jpg
   burger-classic.jpg
   chicken-curry.jpg
   ```

3. **That's it!** The website automatically uses it.

## 💡 Pro Tips

### For Best Results:

1. **Consistent Style**
   - Use similar photo styles (all overhead, or all side views)
   - Same lighting mood
   - Same type of plates/backgrounds

2. **Image Specs**
   - **Size**: 600x400px (after resizing)
   - **Format**: JPG for photos, PNG for transparency
   - **File size**: < 200KB each (use TinyPNG!)

3. **Naming Convention**
   ```
   pizza-margherita.jpg     ✅ Good
   Pizza Margherita.JPG     ❌ Bad
   IMG_1234.jpg             ❌ Bad
   ```

4. **Matching Names**
   Your image names must match `menu-data.js`:
   ```javascript
   image: "assets/menu/pizza-margherita.jpg"
   ```
   So save your file as: `pizza-margherita.jpg`

## 🖼️ Alternative: Use Your Own Photos

### Take Your Own Photos (Best Option!)

**Why?**
- Shows YOUR actual food
- Customers see what they'll get
- Builds trust
- Unique to your restaurant

**How to Take Good Food Photos:**

1. **Lighting**
   - Use natural light (near window)
   - Avoid flash
   - Best time: morning or late afternoon

2. **Composition**
   - Overhead view (bird's eye)
   - Or 45° angle
   - Show the whole dish

3. **Background**
   - Clean table
   - Simple plates (white is best)
   - Minimal distractions

4. **Phone Camera is OK!**
   - Modern phones take great photos
   - Clean the lens first!
   - Use HDR mode if available

5. **Editing (Optional)**
   - Brighten slightly
   - Increase saturation a bit
   - Crop to 3:2 ratio
   - Use free apps: Snapseed, VSCO

## 🔧 Image Troubleshooting

### Image not showing?

**Check:**
1. File is in `assets/menu/` folder ✓
2. File name matches exactly (case-sensitive!) ✓
3. Extension is `.jpg` or `.png` ✓
4. No spaces in filename ✓
5. Refresh browser (Ctrl+F5) ✓

### Image too large?

1. Go to https://tinypng.com/
2. Compress the image
3. Replace the file

### Image wrong size?

1. Go to https://www.iloveimg.com/resize-image
2. Resize to 600x400px
3. Download and replace
