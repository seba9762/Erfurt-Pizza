# Assets Directory

This directory contains all the images and media files for the Erfurt Pizza website.

## Directory Structure

```
assets/
├── menu/               # Menu item images
│   ├── pizza-*.jpg
│   ├── burger-*.jpg
│   ├── *-curry.jpg
│   └── ...
├── hero-pizza.png      # Hero section main image
├── about-img.jpg       # About section image
└── placeholder.jpg     # Fallback placeholder image
```

## Image Requirements

### Menu Item Images
- **Format**: JPG or PNG
- **Dimensions**: 600x400px (3:2 ratio)
- **File Size**: < 200KB (optimized for web)
- **Naming**: Use lowercase, hyphenated names matching the menu items

### Hero Image
- **File**: hero-pizza.png
- **Dimensions**: 1000x1000px
- **Format**: PNG with transparency
- **Purpose**: Main hero section image

### About Image
- **File**: about-img.jpg
- **Dimensions**: 800x600px
- **Format**: JPG
- **Purpose**: Restaurant interior or food preparation image

### Placeholder
- **File**: placeholder.jpg
- **Dimensions**: 600x400px
- **Purpose**: Fallback for missing images

## How to Add Your Images

1. Take high-quality photos of your menu items
2. Resize and optimize them using tools like:
   - https://tinypng.com/ (for compression)
   - https://squoosh.app/ (for resizing and optimization)
3. Name them according to the menu-data.js file
4. Place them in the appropriate directory

## Quick Image Setup

If you don't have custom images yet, you can:
1. Use the placeholder image for all items temporarily
2. Source stock images from:
   - Unsplash (https://unsplash.com/s/photos/pizza)
   - Pexels (https://www.pexels.com/search/food/)
3. Take photos of your actual menu items (recommended!)

## Image Optimization Tips

- Use JPG for photographs
- Use PNG for images with transparency
- Compress images before uploading
- Use consistent dimensions for menu items
- Consider using WebP format for better compression
